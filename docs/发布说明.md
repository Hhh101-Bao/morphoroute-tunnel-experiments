## 4. 代码级修正（最小改动，均附理由）

| 文件 | 修改 | 理由与影响 |
|---|---|---|
| `WSL2 与 Python 依赖文件/requirements-main.txt` | 删除 `openmim==0.3.9` | 工程未使用 `mim`/`openmim`；`mmcv==2.1.0` 由环境安装脚本从官方预编译轮子安装。`test_environment_install_script.py` 原本就断言 requirements 中不得出现 openmim。 |
| `61 项自动化测试/test_environment_install_script.py` | 路径改为 `ProjectLayout` 发现 | 原测试硬编码 `scripts/setup_wsl.sh` 与 `environment/requirements-main.txt`（英文旧布局），在中文化交付布局下必然 `FileNotFoundError`；改为布局发现后两种布局都能测试，断言不变。 |
| `61 项自动化测试/test_morphoroute_amp_numerical_policy.py` | 改为测试 `apply_strict_fp32_config` | 原测试断言“配置构建器输出 dict 型 `loss_scale` 与 `numerical_stability_audit`”，该策略已迁移到 `morphoroute.runtime.strict_fp32.apply_strict_fp32_config`（构建器仍输出 `"dynamic"`，由严格 FP32 入口在解析后移除）。测试意图保持不变：B4/B5/B6 使用同一套标定策略，并新增对非法变体/模式的拒绝检查。 |
| `工程辅助运行脚本/实验断点恢复工具.py` | 通过 `install_module_alias` 加载 `统一实验运行器.py` | 原文件 `from run_experiment import main` 依赖已删除的旧版重复运行器；修复后行为不变（统一运行器 + `--resume`）。 |
| `工程辅助运行脚本/全部实验空运行检查工具.py` | 修复导入与配置目录解析 | 原文件导入不存在的 `generate_configs` / `run_experiment`，且默认配置根写死为 `configs/`（本工程不存在），脚本实际不可用；现改为布局发现 + 标准包别名，并支持 `--profile`。 |

以上修改均保持入口契约、配置内容、数据路径与训练逻辑不变；不涉及模型、损失、划分、阈值或评价口径。
