# 实验运行指南

## 1. 直接运行

每个中文 `.py` 都是完整入口，不需要与其他脚本拼接。程序会自动：

1. 读取当前档位配置和严格划分数据清单；
2. 检查前置实验及文件哈希；
3. 缺失时按无环依赖图依次执行；
4. 自动进入 `main`、`yolo` 或 `stats` WSL2 隔离环境；
5. 训练、用 D2 选最优检查点、在授权数据划分上预测；
6. 写出 CSV/XLSX/JSON 和 PNG/PDF；
7. 失败后再次运行时从兼容检查点恢复。

常用命令：

```powershell
python ".\19 个独立实验运行入口\01数据清单、去重与五类完整性审计.py"
python ".\19 个独立实验运行入口\05同骨干 Mask2Former 共享主基线实验.py"
python ".\19 个独立实验运行入口\09B0–B11 完整消融实验.py"
```

## 2. 三种模式

```powershell
# 仅检查，不训练
python ".\19 个独立实验运行入口\05同骨干 Mask2Former 共享主基线实验.py" --dry-run

# 五类合成数据、128×128、3 次优化器更新的三阶段真实代码链验证
python ".\19 个独立实验运行入口\05同骨干 Mask2Former 共享主基线实验.py" --smoke-test

# 默认本机正式实验
python ".\19 个独立实验运行入口\05同骨干 Mask2Former 共享主基线实验.py"
```

Smoke 自动使用独立合成数据和 `outputs\smoke_runs`，不会读取正式 D4，也不能进入正式统计；正式实验仍按所选档位使用 640×640 或 1024×1024。

## 3. 本机资源策略

RTX 4050 Laptop 6 GB 采用物理 batch=1、AMP、梯度累积、梯度检查点和逐模型串行运行。B0–B11 五种子会耗时很长，但可随时停止并重新运行同一个入口继续。不要并行启动多个训练入口。

发生 CUDA OOM 时按顺序：

1. 关闭占用独显的软件；
2. 重新运行同一入口恢复；
3. 明确切换 `--profile local_6gb_fallback`。

Fallback 结果只作预实验，不能与 `local_6gb` 或 `sop_full` 合并。

## 4. 自动实验顺序

主要依赖链为：

`EXP-00 → EXP-01 → 强基线/路由对照 → EXP-09 → EXP-12:prefreeze → EXP-10 → EXP-11 → EXP-12:external → EXP-15`

EXP-12 被拆为同一入口下的 `prefreeze` 与 `external` 两个内部阶段，避免冻结链循环。用户通常不需要手工指定阶段。

## 5. D4 一次性规则

EXP-11 运行前会验证 EXP-10 冻结清单中所有文件及 SHA-256，并要求输入：

```text
I UNDERSTAND D4 IS ONE-SHOT
```

随后写入一次性开始标记，再对 B9 和 B0 执行 D4 合并及 TC/DACL 分域评价。D4 结果不得用于重新选择模型、阈值、校准器或后处理。

## 6. 输出与判读

所有正式输出位于 `outputs\experiments`。每次运行包含 `run_manifest.json`，记录配置、档位、seed、状态和哈希。

- `completed`、`completed_sealed`、`completed_locked`：成功终态；
- `completed_smoke_only`：仅代码链验证；
- `failed_*`：保留失败证据，修正后可恢复。

严格 AP 使用预测分数排序与 101 点插值，报告 Box/Mask AP50、AP75、AP@[.50:.95]、逐类 AP和最差类 AP。裂缝结构指标包含 clDice、断裂率和连通分量误差；面状病害包含 Boundary-F1、HD95 和相对面积误差。资源、可靠性、量化和序列效率分别保存在对应实验目录。
