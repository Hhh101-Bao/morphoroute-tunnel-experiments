# 数据集说明

本仓库只包含代码、配置、文档与关键审计产物，**不包含图像数据**。

## 1. 五类病害

| 英文键 | 中文名 |
|---|---|
| `crack` | 裂缝 |
| `water_leakage` | 渗漏水 |
| `spalling` | 剥落 |
| `efflorescence` | 泛碱 |
| `exposed_rebar` | 露筋 |

类别顺序由 `metadata/class_mapping.json` 的 `class_order` 固定，全工程共用。

## 2. 划分原则

- D1–D3 来自 TACK TA/TB 与 DACL 官方 train，按**组**（group）划分为 `train` / `val` / `test_internal`。
- D4 为 TACK TC 未见隧道与 DACL 官方 validation 的组合冻结外部测试集。
- 所有图像与标注逐字节复制；未缩放、裁剪、增强、压缩或格式转换。
- TACK 标注保留原始 PNG 语义掩膜；DACL 标注保留原始 JSON 多边形。
- TACK 的 `instances` 统计按“每幅图每个非空语义类别记 1”；DACL 按 JSON 中映射后的多边形数量统计。
- TC 子域本身不含剥落与露筋，D4 的五类完整性由 TC + DACL_external 组合保证；评价须同时报告两个子域。

## 5. 目录结构

```text
铁路隧道多病害实例分割_原始影像严格划分_v1/
├─ metadata/
│  ├─ split_manifest.csv      # record_id、logical_split、来源、分组、类别、宽高、SHA-256
│  ├─ class_mapping.json
│  ├─ split_summary.json
│  ├─ class_distribution.csv
│  ├─ duplicate_audit.csv
│  ├─ source_exclusion_audit.csv
│  ├─ verification_report.json
│  └─ README_划分说明.txt
├─ D1_D3_internal/
│  ├─ train/{images, annotations_original}/
│  ├─ val/{images, annotations_original}/
│  └─ test_internal/{images, annotations_original}/
└─ D4_external_frozen/
   ├─ TC_unseen_tunnel/{images, annotations_original}/
   └─ DACL_external/{images, annotations_original}/
```

`split_manifest.csv` 是文件、来源、分组、类别与 SHA-256 的权威清单；数据物化（EXP-01 之后）会据此生成 COCO/YOLO 派生数据到 `outputs/derived/`，不会写回本目录。

## 6. 获取方式

数据集不随代码仓库分发。请按论文的数据可得性声明获取；使用时须遵守 TACK 与 DACL 原始数据集的许可条款。
